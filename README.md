# SUDAN STORE

تطبيق سوق إلكتروني سوداني متعدد البائعين مبني باستخدام Flutter.

## تشغيل المشروع
1. ثبّت Flutter وAndroid Studio على جهاز كمبيوتر أو استخدم بيئة بناء سحابية.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

## الحالة الحالية
هذه نسخة واجهة أولية (Prototype) تعرض الصفحة الرئيسية والأقسام والمنتجات التجريبية.
تسجيل الدخول، المتاجر، الطلبات، الدفع، وSupabase لم يتم ربطها بعد.
